What this project is

311 is New York City's hub for non-emergency complaints — illegal parking, residential noise, missing heat, blocked driveways. This project turns those raw records into a sequence of reusable data products: a cleaned analytic dataset, a complaint-text taxonomy, geospatial and operational scorecards, a neighborhood-equity audit, and a forecasting model for how long a request will take to resolve.

Note on the data window: the analysis is scoped to 2025–2026, where 2026 is partial-year (labeled YTD). Response-time metrics use only rows with valid closure intervals, and data-quality flags are preserved rather than dropping messy rows globally.

A few headline findings

Volume is concentrated. Illegal Parking (~742K), Residential Noise (~560K), and Heat/Hot Water (~492K) dominate complaint volume; Brooklyn files the most requests of any borough.

Resolution time is predictable, to a point. A histogram gradient-boosting model lifts overall accuracy from a 59% majority baseline to ~66%, and recovers slow ("30+ day") cases that the baseline misses entirely — though mid-range buckets remain the hardest to call.

Equity matters. The fairness layer adjusts neighborhood comparisons for demographics so disparities aren't confounded by raw population differences.

How it's built
01 · INGEST

Local storage

Raw 311 records land in SQLite and yearly Parquet so analysis never reparses the source CSV.

02 · CLEAN

Analytic base

A standardized 2025–2026 Parquet with time features and preserved QA flags.

03 · ENRICH

Text taxonomy

Issue families, subtypes, and closure-language groupings layered onto each record.

04 · BUILD

Reusable artifacts

Geo, operations, fairness, and predictive builders write tidy Parquet scorecards.

05 · EXPLAIN

Notebooks

Six notebooks narrate each layer — the pages linked above.

06 · SHIP

Dashboard

A Streamlit app reads the artifacts into one interactive final product.

Stack: Python · pandas · NumPy · PyArrow · scikit-learn · GeoPandas / Shapely · Matplotlib · Streamlit & pydeck.  The interactive dashboard runs on Streamlit Community Cloud (it needs a live server, so it isn't part of this static site) — open it here ↗.
